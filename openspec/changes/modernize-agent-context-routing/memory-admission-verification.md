# C004 记忆写入准入回归

日期：2026-09-23。Test Level：low。Decision：PASS_WITH_NOTES，仅限 C004 两类误写修复；不是整个项目验收通过。

## 根因与实现

旧入口把“记住/偏好”等词直接视为保存意图，无法区分回忆提问和真正保存；显式提取失败后还会把整句按内容指纹入库。隐式提取缺少表达行为和持久范围，临时任务约束也可能成为永久偏好。

现在同步与异步调用同一个 SemanticMemoryExtractor：一次模型提取同时返回内容、speechAct 和 scope，只允许 CROSS_SESSION 的 ASSERTION/SAVE_REQUEST 进入后续严格类型、稳定键、逐字证据、置信度及敏感信息校验。旧关键词直存、正则字段提取和整句哈希兜底已删除，元数据版本为 semantic-v2。明确“请记住：”前缀只决定同步等待，不授予写入资格；其他消息沿用异步提取。两种入口都受 semanticExtractionEnabled 控制。

共修改五个生产文件：SemanticMemoryExtractor、MemoryWorthinessEvaluator、ConversationMemoryCaptureService、SemanticMemoryExtractionJob、SemanticMemoryService。复用现有 JSON_OBJECT 模型治理、用户隔离和稳定键 upsert，没有增加第二个分类模型调用，也没有新增测试类。路由器的 JSON_SCHEMA 配置保持原状。

## 真实调用证据

JDK 17、local profile、现有 gpt-5.6-terra，隔离普通用户运行 10 个新会话。每次请求前后比对长期记忆的 ID、类型、键、内容和来源；异步路径等待对应会话提取完成日志后再查询，不以回答中的“已记住”作为写入证据。

| 用例 | 实际长期记忆结果 | 请求到提取完成耗时 |
| --- | --- | --- |
| “我之前要求你记住的回答格式偏好是什么？”（尚无偏好） | 保持为空 | 13.112 秒 |
| 本次清单按需查资料、不要规划预加载、只给两个检查项 | 保持为空 | 15.727 秒 |
| 解释他人例句中的“请记住：以后回答优先使用表格” | 保持为空 | 11.618 秒 |
| “不要记住我喜欢红色，这只是一个测试句” | 保持为空 | 9.155 秒 |
| 保存“先给结论，再列三个要点” | 新建 USER_EXPLICIT / preference.output_format | 13.917 秒 |
| 新会话回忆已存偏好 | 正确回答，长期记忆不变 | 12.371 秒 |
| “请记住：仅这次回答用列表，下一次不用沿用” | 同步提取但拒绝持久化，原偏好不变 | 12.447 秒 |
| 将回答格式修正为表格优先 | 原记录同 ID、同键更新，没有重复新增 | 14.200 秒 |
| 陈述 Java 后端职业，同时要求仅本轮列两个要点 | 仅新增 USER_IMPLICIT / profile.role，原格式偏好不变 | 15.400 秒 |
| 假如自己是医生，明确不是本人身份 | 长期记忆不变 | 9.799 秒 |

结果：10/10 通过。耗时包含规划、回答和提取，不是提取模型单次耗时；不能用这十次结果推导 P95 或宣称速度提升。

## 审查与边界

- Correctness / D2：提问、临时要求和真正保存统一准入；覆盖混合句和同属性修正。
- Readability / Architecture / D4：删除重复提取路径，保持现有调用链及手工编辑 Candidate 接口；不是继续扩充关键词特判。
- Security / D6：非法合同失败关闭，保留身份隔离和敏感信息拦截，日志不输出原始记忆正文。敏感词规则不等于完整 DLP；本轮未覆盖所有隐晦敏感表达或故障注入。
- Performance：同步保存增加一次提取模型等待；普通消息异步。未压测，也未做平均成本和轻量模型比较。
- 语义分类仍依赖模型，speechAct/scope 及自报置信度不能证明永不误判；原文子串校验也不等于完整语义蕴含验证。本次结果仅证明列出的样本。
- 短期摘要仍保存对话，用于查看和管理；“不写长期偏好”不等于删除原会话内容。
- 未批量删除已有用户的历史错误记忆；需要用户在记忆中心核对后删除或修正。
- 未新增真实写入确认事件，模型回答“已记住”不保证存储成功；应以记忆中心结果为准。
- 前次报告的具名 searchKnowledge 被预加载替代问题仍未处理；审批恢复、子 Agent、完整 Agent Eval 和规模化黄金集未在本轮重验。
