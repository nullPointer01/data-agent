# AiServices 受治理工具执行
用户已在本会话批准五步迁移方案并要求“那就开始搞吧”。框架接管正常多轮工具交互，Harness 保留预算、权限、审批、持久化和追踪。
## 成功标准
- SC1：正常同步和流式工具对话使用 AiServices，多工具结果按原生消息回填。
- SC2：整批准入先于任何工具执行；审批暂停后零后续模型调用，暂停不能转换为工具成功。
- SC3：恢复不伪造用户消息、不重复执行已批准动作；共享根 Run 预算与取消仍有效。
- SC4：删除旧循环及专属处理器，同步中文说明。
验证：实现代理负责；JDK17 + 本地 1.20.2 框架的临时行为检查和编译。真实外部端到端另列未验。
边界：不新增仓库测试类，不改数据库协议，不绕过 Pipeline，不提交推送，不覆盖既有修改。
