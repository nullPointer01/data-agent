# Assumptions

## A001 RAG JPA 的范围

- 假设：用户所说“JPA 那套不要了”指删除 RAG 的 `JpaFullTextRetriever`，不删除业务持久化的 Spring Data JPA。
- 来源：用户陈述与当前 RAG 讨论上下文。
- 置信度：高。
- 验证方式：人工审核 proposal；编码阶段检查删除范围仅限 RAG 全文召回及失效 Repository 查询。

## A002 Elasticsearch 成为必要依赖

- 假设：RAG 启用时允许要求 Elasticsearch 可用，不需要 SQL LIKE 降级。
- 来源：用户明确要求删除 JPA 全文召回。
- 置信度：高。
- 验证方式：启动集成测试与 `/api/v1/rag/health` 验收。

## A003 外部模型协议

- 假设：目标 Embedding 服务提供 OpenAI 兼容 `/embeddings`；目标 Reranker 提供可配置 `/v1/rerank` JSON API。
- 来源：项目现有 OpenAI 兼容模型接入与主流 Rerank 服务协议。
- 置信度：中。
- 验证方式：编码前使用实际服务执行一组 curl 探测，并把响应样例固化为契约测试。

## A004 目标模型尚未最终确定

- 假设：不预先认定 BGE-M3、bge-large-zh-v1.5 或其他模型最优，最终选择由黄金集决定。
- 来源：当前缺少真实基线。
- 置信度：高。
- 验证方式：同一黄金集至少对比当前模型与一个中文模型。

## A005 数据规模未知

- 假设：当前无法根据真实 Chunk 数确定 IVF_FLAT/HNSW、nlist 和检索参数的最优值。
- 来源：代码只提供运行时内存计数，缺少稳定生产数据统计。
- 置信度：高。
- 验证方式：记录实际向量数量与 P95，再决定是否调整 Milvus 索引类型。

## A006 现有工作区改动受保护

- 假设：当前未提交的 ReAct、工具、追踪、前端和面试文档改动均属于用户，不能回退或覆盖。
- 来源：`git status --short`。
- 置信度：高。
- 验证方式：每个任务执行前检查 diff；只修改 tasks.md 声明的文件。

## A007 Java 和测试基线

- 假设：项目应当只以 JDK 17 构建；用户要求删除全部现有测试源码，而不是迁移其中遗留的 `ReActToolCall` 和 `parseToolCall` 引用。
- 来源：用户明确陈述、pom.xml、生产代码、终端 JDK 检查和 JDK 17 干净测试编译结果。
- 置信度：高。
- 验证方式：确认 `src/test/java` 不存在；Maven Enforcer 分别在 JDK 8 与 JDK 17 下验证；JDK 17 执行干净 `verify`。

## A008 JDK 版本范围

- 假设：用户所说“完全升级到 JDK 17”表示所有构建和运行入口固定 17，而不是允许 17 及以上版本。
- 来源：用户明确要求完全升级到 JDK 17，且当前目标不是 JDK 21。
- 置信度：高。
- 验证方式：人工审核提案；Maven Enforcer 使用 `[17,18)`，CI 与容器显式使用 17。

## A009 Docker 范围

- 假设：现有 `docker-compose.yml` 继续只管理基础设施；新增应用 Dockerfile 用于固定 Java 构建与运行环境，不在本轮改变本地服务拓扑。
- 来源：仓库审计显示 Compose 中没有 Java 应用服务。
- 置信度：高。
- 验证方式：Dockerfile 独立构建验证，Compose 配置保持不变。

## A010 黄金集由真实业务标注提供

- 假设：当前仓库没有可以证明真实 sourceId/chunkId 的30条业务标注，不能为了完成任务生成虚假黄金集。
- 来源：用户要求评测召回和精排是否有效；当前代码与配置中没有现成标注集。
- 置信度：高。
- 验证方式：实现固定外部JSON加载和严格校验；只有配置真实数据集并实际运行后才填入Recall、MRR、NDCG和P95。

## A011 教学实验数据不属于业务证据

- 假设：用户需要一套自己可以逐步操作的可控知识库，以理解 RAG 工程化验证，但不会把虚构教学集的结果作为真实业务指标。
- 来源：用户确认创建独立的 RAG 教学实验库；现有 A010 继续有效。
- 置信度：高。
- 验证方式：材料固定放在 `examples/rag-evaluation-lab/`，不修改生产默认数据集路径；文档和答案册显式声明证据边界。

## A012 首个外部模型组合

- 假设：首个真实联调使用硅基流动国内站当前标记免费的 `BAAI/bge-m3` 与 `BAAI/bge-reranker-v2-m3`，仅用于教学资料和项目验证，不把免费策略视为生产 SLA。
- 来源：用户要求不运行本地模型、不花钱并尽量提高召回效果；2026-09-03 官方国内价格页。
- 置信度：高。
- 验证方式：用户创建 API Key 后分别探测 `/v1/embeddings` 与 `/v1/rerank`；价格和限额在每次正式部署前重新核对。

## A013 测试与编译策略仍需重新确认

- 假设：用户本轮同意继续企业化改造和真实黄金集评测，但没有明确撤回此前“不新增测试、不编译”的要求。
- 来源：用户历史决定与本轮“按照你说的来”。
- 置信度：高。
- 验证方式：进入 Coding 前由用户明确确认是否允许恢复少量 HTTP 契约测试和一次 JDK 17 编译；未确认前只执行静态检查与获授权的外部 API/运行时评测。
