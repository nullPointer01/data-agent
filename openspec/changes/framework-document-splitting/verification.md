## 范围与限制

未新增仓库测试类，未修改前端，未调用付费模型、业务数据库、Embedding 服务、Milvus 或 Elasticsearch，未重建历史索引。本轮只负责任务账本列出的文件和相关文档片段，保留开始前已有工作区改动。

框架 overlap 是完整句子的重叠上限，不是固定字符窗口。默认句子检测使用英文 OpenNLP 模型；中文必要时降级到更细粒度切分，不是模型语义分块。code point 适配防止代理对拆断，但不保证复合 emoji 或组合字符簇完整。过长代码/表格仍可能跨块，只保留结构标签，不承诺补齐围栏或表头。

框架可能规范化空白；来源范围按非空白内容对齐。重复内容可能存在多个合理位置，本实现返回单调、满足完整覆盖的有效对齐，不能宣称恢复 SDK 内部的唯一位置。无法对应的内容拒绝生成伪偏移。父级聚合规则保持现状。

历史向量与全文索引不会自动变化。重启后先上传新的样本文档，确认切片/引用及父级上下文，再通过项目现有重新索引流程处理需要迁移的历史文档；不要直接清空整个集合。真实黄金集需要核对变化后的 chunkId 标注并重新评测，当前不宣称检索质量或速度提升。
