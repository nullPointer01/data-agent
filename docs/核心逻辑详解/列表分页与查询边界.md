# 列表分页与查询边界

## 本轮范围

2026-10-09 第一批完成用户管理、审计日志、执行追踪、个人记忆；第二批继续完成 Agent/专家、模型、Skill/版本历史、数据源、知识、资源中心、审批、评测运行/样本证据和 Token 明细。2026-10-10 第三批补齐角色/权限与个人模型/能力配置目录。管理展示、配置选择、运行时授权和聚合看板具有不同读取边界，不能把所有集合机械改成只读第一页。

| 页面 | 查询接口 | 分页与边界 |
| --- | --- | --- |
| 用户管理 | `GET /api/v1/admin/users?page=0&size=20&query=关键词` | 页码分页，返回 `items/page/size/total/enabledCount/adminCount`；搜索与聚合统计覆盖全部匹配账号 |
| 审计日志 | `GET /api/v1/audit-logs?size=20&query=关键词&userId=用户ID&after=游标` | 当前租户内按创建时间、数值 ID 倒序；用户过滤和搜索在 SQL 执行 |
| 执行追踪 | `GET /api/v1/agent-traces?size=20&query=关键词&userId=用户ID&after=游标` | 当前租户内按创建时间、traceId 倒序；列表不下载完整 JSON 证据，打开详情才读取 |
| 个人记忆 | `GET /api/v1/memories?size=20&tier=LONG_TERM&after=游标` | 同时约束登录租户和用户，按创建时间、memoryId 倒序；只为当前页批量查询向量任务状态 |

游标页统一返回 `success/items/size/hasMore/nextCursor`，查询 `size + 1` 条判断后续是否还有记录。每页 1～100 条，页面默认 20 条，可选 10/20/50。`after` 留空表示首页，下一页使用响应的 `nextCursor`；前端保存已访问的页边界以支持上一页。创建时间相同以唯一键继续定位；历史空时间排在最后，使用独立空时间分支继续翻页。刷新回首页获取最新记录。

游标只是位置，不是授权。服务端仍在每次查询中追加租户/用户条件；不能通过传入其他人的游标绕过身份边界。管理用户原本是平台级管理员权限，本轮保留该范围；审计和追踪仍只查询当前租户，个人记忆仍只查询本人。

搜索按原样字符串匹配，`%` 和 `_` 不作为通配符，最多 200 字。搜索或页大小改变自动回首页；页面防抖 300ms，取消旧 HTTP 请求并再次校验响应版本，避免迟到请求覆盖新页。翻页失败显示错误与重试，不将失败伪装成空库。

## 第二批：资源与运行记录

以下列表统一采用 `page/size`，返回 `success/items/page/size/total`。页码从 0 开始，每页仍限制 1～100 条。计数与分页读取在同一事务中，末页删除或查询越界时退到最后有效页；搜索与筛选先于 LIMIT，不在浏览器过滤当前页。时间相同时追加唯一键排序；页码查询不承诺跨请求的数据库快照，并发修改排序字段仍可能改变页边界。

| 列表 | 接口 | 作用域与筛选 |
| --- | --- | --- |
| 管理 Agent | `GET /api/v1/agents` | 当前租户；query 搜索名称/描述/归属 ID/用户名/昵称，ownerId、role=PRIMARY/EXPERT、enabledOnly 均在 SQL 处理 |
| 我的专家 | `GET /api/v1/my/agents?role=EXPERT` | 登录租户 + 当前用户；主 Agent 与专家不再混在前端过滤，主 Agent 绑定单独查询 |
| 模型 | `GET /api/v1/models/list` | 当前租户 + default 共享配置；query 搜索名称/厂商代码/模型名/地址；凭据沿用脱敏 |
| Skill | `GET /api/v1/skills/list` | 当前租户 + default 共享配置；query 搜索名称/描述/来源 |
| Skill 历史 | `GET /api/v1/skills/{id}/history` | 沿用当前租户可维护 Skill 的校验，按版本和 ID 倒序；回滚按版本定点查询 |
| 数据源 | `GET /api/v1/datasources/list` | 当前租户；query 搜索名称/描述/类型/主机/库名；密码沿用脱敏 |
| 个人知识 | `GET /api/v1/knowledge/list` | 当前租户 + 当前用户；query 搜索名称/描述/文件名/来源；不读取知识正文，只装配本页索引状态 |
| 资料中心 | `GET /api/v1/resources/assets` | 保留当前租户原有可见范围；keyword/resourceType/status 在数据库 UNION ALL 后过滤，统一排序分页 |
| 动作审批 | `GET /api/v1/agent-approvals` | 服务端重验审批权限和租户；status 筛选先于分页，不读取加密动作载荷；本页申请人与审批人只查询最小身份字段 |
| 评测数据集 | `GET /api/v1/agent-evals/datasets` | 管理员当前租户 READY 版本；用于配置选择 |
| 评测运行 | `GET /api/v1/agent-evals/runs` | 管理员当前租户；不再限于最近 50 条 |
| 评测样本证据 | `GET /api/v1/agent-evals/runs/{id}/samples` | 校验运行归属，再分页读取该固定版本的启用样本及本页结果，未执行的样本也可见 |
| Token 明细 | `GET /api/v1/token/usage-records` | 当前租户，按 created_at/id 倒序；不再预取 500 条后切片 |

资源中心在 SQL 内合并文件和知识，仅为分页后的文件读取内容长度；计数/排序不搬运正文。个人知识统计与资料中心统计使用数据库聚合，不再加载整批实体求和。统计独立于翻页：个人知识总量属于本人全部知识，资料中心总量属于租户全部资产，Token 总量/分布沿用独立汇总；页面局部的启用数、待审批数和输入/输出 Token 明确标注“本页”。

模型管理分页直接查库，删除旧的仅按租户缓存全量列表的注解、缓存名和失效配置，避免不同页码/搜索词命中同一响应；模型详情及运行时客户端缓存仍按原规则维护。

Agent 归属筛选使用可搜索、可翻页的用户选择器，不依赖当前 Agent 页出现的用户。展示名称仍按本页实际归属 ID 批量解析。模型名称映射、评测 Agent/数据集选择使用 `loadListOptions` 逐页读取完整候选，不将第一页冒充全部配置；它们属于配置选择而非资源展示表。个人模型/能力目录在第三批单独收敛范围。

评测报告 `GET /runs/{id}` 现在只返回运行摘要和全量指标，不再带 samples；样本证据由新接口单独分页。状态轮询与样本页刷新各自处理，切换页或报告后旧请求不能改写当前列表。指标来自运行完成时保存的全数据集快照；仅旧报告缺少快照时按整个固定数据集重算，绝不能用当前样本页计算总体指标。

知识页只在当前页索引未完成时周期刷新本页，任务全部终结后停止。删除旧的全量 `/knowledge/index-tasks` 页面接口；遗留清理任务由已有索引运维入口查询。历史记录与详情、更新、删除、审批决定仍保留原有身份和权限检查。

## 第三批：角色权限与配置目录（2026-10-10）

| 查询 | 分页协议 | 边界 |
| --- | --- | --- |
| `GET /api/v1/admin/rbac/roles` | `page/size/query`，返回 `items/page/size/total/enabledCount/systemCount` | 保留平台级管理员权限；先分页角色，再 JOIN 本页权限编码，避免角色被权限数量挤出页或逐角色查询 |
| `GET /api/v1/admin/rbac/permissions` | `page/size/query`，返回 `items/page/size/total` | 保留平台级范围；编码、名称、说明、资源类型、动作在 SQL 搜索 |
| `GET /api/v1/my/models` | `page/size/query`，返回 `items/page/size/total` | 当前租户及 default 共享、仅启用模型；SQL 只投影 modelId/displayName/modelName/provider/isDefault，不查询或解密 API Key，也不返回/搜索 Base URL |
| `GET /api/v1/my/capabilities` | 必填 `type=TOOL/SKILL/SUB_AGENT`，可选 `size/after/query/agentId`；返回 `items/size/hasMore/nextCursor` | 每次最多读取 size+1 个候选，Skill 仅当前/default 租户，专家仅本人且排除自身，工具仅当前租户可见注册项 |

角色与权限表各自搜索、翻页，指标覆盖各自全部匹配结果。用户编辑的角色选择器通过 `loadListOptions` 按每页 100 条拿齐候选，失败时显示可重试错误并阻止打开/保存；删除原来网络失败仍提供 USER/ADMIN 的伪选项。角色/权限页面的旧全量缓存、无消费者的领域列表方法及旧查询已删除，实际登录鉴权和角色解析保持原有完整权限读取。

能力目录按稳定 ID 升序推进。Tool 在有限内存注册表中先鉴权再分页，不把未授权工具名放进游标；Skill/专家在 SQL 完成租户/归属/自引用/搜索过滤和 LIMIT，随后按实时有效工具权限复核专家的可用权限。数据库候选页的游标取过滤前边界，只有描述符通过 RBAC 才会返回。某一页可能为空但 hasMore=true，客户端必须继续读取，不能因本页无可用项提前终止。游标只定位，不授予权限；换类型的游标被拒绝，每次请求重新解析身份。

聊天设置使用 `loadAgentConfigurationOptions` 逐页读取模型和三类能力；专家设置只读取 TOOL/SKILL，避免为不支持的委派配置查询全部专家。完整读取成功才标记配置可编辑；后续页失败、重复游标或非法分页响应均阻止保存。刷新取消旧请求，迟到选项不覆盖新目录。绑定模型已停用/不可选时仍显示原 modelId 的占位选项，不能将它伪装成“跟随默认模型”。能力包及精确绑定仍按完整候选操作，不会把其他页的能力当成已删除。

这仍是完整配置选择器：浏览器最终持有全部可授权候选，并非虚拟滚动选择器，也不承诺跨 HTTP 请求的配置快照。目录规模继续增长时可以改成按需搜索和批量解析已选身份，但必须同时改能力包选择语义。运行时目录、保存准入、防引用环和授权快照不使用页面游标，保留原实现；其中全量快照查询仍是后续运行时性能优化点，不能声称本批已解决。

本批不新增表、字段或 Flyway 迁移。RBAC 复用编码主键排序；Skill/专家游标复用 V1 的租户、本人/主专家索引及 InnoDB 二级索引隐含主键，模型复用租户/启用索引。共享租户的合并排序、个人模型优先级排序和 LOCATE 仍可能扫描/排序，实际收益需运行 EXPLAIN 确认，不虚构性能结论。

## 分页前后的差异

原用户列表先查全部用户，并为每个用户查询角色，再在浏览器切片。现在先在 SQL 内对用户分页，再关联角色，用 MyBatis collection 将同一用户的角色合并；用户不会因角色数量占掉多条分页名额，也不会为列表逐用户查询角色和权限。聚合统计使用相同搜索条件，管理员数量只计启用的 ADMIN 角色。

Agent 管理页不再通过全量用户列表解析归属，而是将实际 Agent 的 createdBy 去重、每批最多 100 个，通过管理员接口 `GET /api/v1/admin/users/identities?ids=id1,id2` 只查询 userId/username/nickname。该接口不是用户列表，也不返回密码、邮箱、角色或配额。

原审计、追踪、记忆页面只拿最近 100 条，再通过 DataTable 做前端分页，较早数据无法完整访问。现在三者真正按页查库；DataTable 收到 `serverPagination` 时直接展示本页，不再二次切片。未迁移页面继续沿用原前端分页，后续单独处理。

日志和追踪的“成功/失败/平均耗时”明确标注为本页统计，不为每次翻页增加全表聚合。记忆的画像与总量统计沿用独立接口，仅初始化、手工刷新或记忆变更时重查；普通翻页不重复查询画像和总量。偏好/画像事实/结论卡片仍是最多 20 条的概览，完整记忆表可继续向历史翻页。

删除没有下一条的末页可能返回空页，页面仍允许返回上一页；记忆删除、清理、重置后主动返回首页。用户页超出末页时，服务端按当前匹配总数归到最后一页。当前游标页不提供总页数，也不承诺历史记录被并发删除或修改时仍是完全不变的快照。

## 数据库升级与限制

第一批新增 Flyway `V5__server_list_pagination.sql`；第二批新增 `V6__resource_list_pagination.sql`，增加 13 个资源/归属/历史/审批/Token/样本排序索引。READY 数据集、按状态审批和评测运行复用已有索引（InnoDB 二级索引隐含主键）。没有新增业务表，也不修改 V1～V5 或历史记录。正常重启时由 Flyway 执行；本轮未对业务数据库执行迁移。

组合索引用于身份筛选、排序和边界定位；`LOCATE` 关键词搜索本身仍可能扫描匹配范围，不宣称全文搜索已经索引化。数据规模增长后需结合真实 EXPLAIN、查询分布决定专门的全文索引。页码管理列表仍使用 OFFSET；持续增长的三类记录已使用游标，避免深页 OFFSET。索引的实际执行计划与收益尚未验证。

两批调整了列表响应结构和分页参数；前后端需一同更新。第二批删除 8 个旧列表 DTO、旧全量知识状态接口与已无消费者的查询，保留仍由运行时能力目录使用的配置查询。第三方若仍读取 agents/models/skills/datasources/knowledge/assets/records/history、直接数组响应或 report.samples，需要迁移到 items 和独立样本接口；审批和评测不再接受 limit 控制列表。

第三批的 roles/permissions/my-models 不再返回 roles/permissions/models 包装字段；my-capabilities 不再返回 capabilities 全量数组，调用必须带 type 并遍历游标。前后端同版更新；原个人模型全量 DTO 已删除。

## 静态检查与人工验收

本轮不新增测试类；仅做 JS/JSX 语法与标识符检查、Mapper XML 解析/语句对应检查、源码引用和差异空白检查。没有执行编译、构建、启动、业务库迁移或真实浏览器/SQL 性能验收。

人工验收步骤：

1. 重启后端，确认 Flyway V5/V6 成功；前端使用同版源码或构建产物。
2. 用户管理选择每页 10 条，翻页、搜索第二页以外的用户名、改页大小；多角色用户每页仍按用户计数，统计覆盖全部搜索结果，角色停用时口径一致。
3. 审计和追踪翻到原先 100 条之外，搜索历史记录；快速切换搜索词与用户 ID，结果不能被旧请求覆盖。打开追踪详情仍显示完整证据。
4. 记忆按全部/短期/长期切换并向历史翻页，删除或重置后回首页，画像及统计刷新；另一账号的数据始终不出现。
5. 使用相同创建时间的记录核对跨页不重不漏；历史空时间记录仍能翻到末尾。翻页间插入新记录后继续下一页，刷新首页才应看到新记录。
6. 模拟接口失败，页面应显示错误而不是“暂无记录”；恢复后可重试。篡改游标、超大页和过长搜索应返回校验错误。
7. Agent 管理页核对归属用户名和详情；搜索第二页以外的归属姓名并按账号/主 Agent/专家筛选。解析归属只请求批量 identities；打开归属选择器才请求分页用户查询。
8. 依次在模型/Skill/历史/数据源/知识/资料/审批/Token 页选择每页 10 条，翻到较早记录；搜索不在第一页的条目。删除末页最后一条后应自动退页；共享配置和本人/租户边界不能改变。
9. 知识列表编辑时从详情获取完整正文，不以列表缺少 content 覆盖原文。索引未完成时只刷新当前页，完成后停止；翻页不重复拉取全部任务或统计。
10. 资料中心混合放置文件与知识，含相同时间/不同类型记录；核对统一顺序、筛选、合计数量和双类型同 ID 的独立行。
11. 评测运行和样本分别翻页；运行中切换报告/样本页，完成后最后结果可见。翻样本页不改变全量评测指标，较早运行仍可打开，配置超过 100 个也不丢候选。
12. Token 明细翻过原先 500 条边界，租户/用户总量与模型分布不随翻页变化，输入/输出只表示本页。对查询执行 EXPLAIN，确认索引和真实数据量的影响。
13. 角色和权限分别搜索、翻页；一个角色具有多个权限时仍只占一个角色名额，指标不随翻页变化。角色超过 100 个时用户编辑可选到后续页角色；中途选项失败时不能回退伪默认或保存残缺配置。
14. 当前租户与 default 共享启用模型超过 100 个时，聊天/专家设置仍可选到后续页模型；API 响应与 SQL 投影均不含密钥/地址。停用已绑定模型后设置保留其身份，不隐式换为默认模型。
15. 能力三类各设置 size=1，确认从头到尾遍历；本人专家因工具权限被排除的候选页即使为空也能继续。其他用户专家和未授权工具描述符不可见，未授权工具名不能出现在游标中；编辑自身不能选择自身。
16. 目录读取第二页模拟失败，聊天/专家配置不能保存；恢复后刷新重试。快速重复刷新/离开页面，旧请求不能覆盖新目录。已有跨页绑定保持原样，保存时继续重验权限/可用性/引用环。
