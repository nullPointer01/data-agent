## 一、已冻结的产品定位

Data Agent 是一个用于 Agent 开发岗求职展示的 **Java Agent Harness 参考应用**：

> 用户向自己的个人 Agent 提出问题或任务；Agent 自动判断是否使用模型、个人知识、工具或专家 Agent；结果带可核对的引用和运行证据；高风险动作先暂停并等待审批；管理员在 Control Plane 治理模型、能力、权限和运行质量。

它不是单一的企业问答 Agent，也不是把所有技术概念都暴露给普通用户的管理后台。普通使用面保持简洁，Harness 的工程证据收进管理控制面。

## 二、当前产品结构

### 普通用户

- **我的 Agent**：正式对话入口，配置名称、模型、System Prompt、能力包和已接入专家。
- **专家助手**：创建非默认 Agent Profile，作为受控子 Agent 供个人 Agent 委派。
- **知识**：录入文本或上传知识文档，进入个人 RAG 索引。
- **上下文**：管理会话与长期记忆。

个人 Agent 只暴露四类业务能力包：知识与记忆、文件理解、数据分析、专业技能。页面固定保存 `executionMode=auto`，普通用户不选 Chat/ReAct/Orchestrated、Token 预算和 Tool Schema。

### 管理员 Control Plane

- 运行与质量：运行追踪、动作审批、质量观测、Agent 评测、资源统计。
- 能力配置：模型目录、技能目录、知识与 RAG、数据连接。
- 平台治理：用户、用户 Agent、角色权限、审计。

Harness 管理的是“一次 Agent Run 能如何执行”；管理员管理的是“平台允许哪些用户和能力存在”，两者不是同一概念。

聊天回答不再提供点赞/点踩。对应按钮、前端请求、管理页面、后端接口和质量评分依赖均已移除；质量分只根据执行成功率、耗时和回退率计算。旧库如需物理删除历史反馈表，可手动执行 `sql/drop-agent-feedback.sql`。

所有实际数据表格默认按 10 条分页，可切换为 20 或 50 条；专家助手卡片列表使用相同分页交互，数据不足一页时不展示分页控件。会话列表不分页，默认展示最近 5 条，可展开全部并收起。首页固定数量摘要、质量建议、风险项和能力选择器不属于全量数据列表，不做分页。

“用户 Agent”是治理清单，不是第二套用户配置入口。管理员可按归属用户和角色查看全部 Agent、查看详情并跳转到该用户的运行追踪；不可新增、编辑或删除用户 Agent，只可启用或停用专家助手。每个用户的默认主 Agent 继续展示，但不能停用或删除；用户在“我的 Agent”修改配置后，管理员刷新清单即可看到同一份 Profile 的最新状态。
