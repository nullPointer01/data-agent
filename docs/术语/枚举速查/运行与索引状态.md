# 运行与索引状态

## 内部规划模式

`AgentExecutionMode.PLANNING` 表示目标 Profile 已鉴权、Run 已启动，但 Router 尚未绑定 CHAT、REACT 或 ORCHESTRATED。该阶段无可执行工具；不属于用户可配置模式。规划与最终模式共用 Run ID、控制器和预算。原有 Run 状态不增加 PLANNING，规划时状态仍是 RUNNING。

## 持久索引任务

| 状态 | 含义 |
|---|---|
| PENDING | 已提交，等待工作线程认领 |
| RUNNING | 当前实例持有租约并执行 |
| RETRY | 执行失败，等待下一次退避到期 |
| SUCCEEDED | 对应目标版本已完成写入 |
| FAILED | 已达到五次失败，等待人工重试或内容更新 |
| UNKNOWN | 页面投影：历史知识没有任务记录，不能据此认定索引失败或成功 |

任务 Kind 包含 KNOWLEDGE（最新知识正文）、FILE（重新解析存储文件）、MEMORY（有效长期记忆向量重建）、CONVERSATION（按 Run 保存的加密对话快照）。desiredVersion 是待处理版本，completedVersion 是已完成版本。leaseOwner 是一次认领的随机令牌，不能当作用户身份。重建管理入口不支持 CONVERSATION。

流程见[框架集成与消息生命周期](../../核心逻辑详解/框架集成与消息生命周期.md)，历史批次见[中文检索与索引维护](../../核心逻辑详解/中文检索与索引维护.md)。
